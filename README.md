# Sunlight — Iluminação pensada para a sua casa

Site responsivo de demonstração para uma coleção de candeeiros, com conteúdo em português de Portugal, visual renovado e animações suaves.

## Funcionalidades

- Apresentação dos produtos e da coleção de iluminação.
- Navegação adaptada a dispositivos móveis e acessível por teclado.
- Alternância entre tema claro e escuro, guardada no navegador.
- Sacola de demonstração com contador e confirmação acessível.
- Formulário de novidades com confirmação local.
- Animações de entrada e interação, respeitando a preferência por movimento reduzido.

## Executar

Abra `index.html` num navegador. Não é necessária instalação.

## Nota sobre as demonstrações

Os preços e a sacola são ilustrativos. Não é possível concluir compras ou pagamentos nesta página. O formulário não envia nem guarda dados pessoais.
